## 5. 本地上传与 paper_id

| 改进 | 说明 |
| --- | --- |
| 按 PDF stem 建目录 | `POST /api/upload` → `incoming/<paper_id>/paper.pdf` |
| 中文文件名 | sanitize 保留 CJK（`\u4e00-\u9fff`），不再塌缩为 `paper` |
| 冲突去重 | 同名追加 `_2`、`_3`… |
| `load_bundle` | `paper.id = directory.name`，与上传分配 id 对齐 |
| **FIX2：paper_id 解析** | `POST /api/run` 支持 `paper_id`；路径 mojibake 时仍可定位 `incoming/<id>` |
| UI 一并提交 | 仪表盘 `doRun` 发送 `{source, paper_id}` |

**根因回顾（用户仍无法生成解析）：**  
除早期 ASCII-only `paper_id_from_path` 导致产物落在 `outputs/paper/` 外，中文路径在部分客户端（如错误编码的 PowerShell JSON）会出现 mojibake，`FileNotFoundError` 使 `/api/run` 失败；UI 若只显示灰色 toast，看起来像「没生成」。FIX2 用 `paper_id` 解析 + 红色 `#runError` 横幅修复。

## 6. Web 删除与卡片 UX

| 改进 | 说明 |
| --- | --- |
| 删除论文 | `DELETE /api/papers/{id}`（及 POST 兼容），同时删 incoming + outputs |
| 卡片状态 | 已解析 / 已上传徽章 |
| 主按钮文案 | **「上传并生成解析」**（上传 + `/api/run` 一气呵成） |
| 成功跳转 | 完成后 `location.href=/paper/{id}` |
| 详情轮询 | 产物未齐时每 2.5s 刷新，避免一直「尚未生成」 |
| **FIX2：红色错误条** | `/api/run` 失败时 `#runError` 显示 `detail` 文本 |
