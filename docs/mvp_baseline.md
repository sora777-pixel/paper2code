## 3. 失败原因（真实论文，逐篇）

真实三篇的失败**不在 MVP 层**，而在它上游的**摄取层**：MVP 脚手架拿不到可回放的内容。

| 论文 | 直接原因 | 根因（详见诊断报告 §3） |
| --- | --- | --- |
| Hsp70–BAG2 主文 | 图表说明 32 张但**出图 0 张**；脚手架警告"既无可用表格也无伪代码" | ① 正文引 `Table N` ×15 但**表格零召回**（默认策略漏三线表，换 `text` 策略可得 19 张）；② 32 张图全为**位图且 `image_path` 为空** → 数字化器无从下手 |
| PBEE 主文 | 同左；且**情形 A 判定正确却无法对标** | ① 表格零召回（`lines`=4 / `text`=8）；② 仓库**已克隆成功**（`github.com/chavesejf/PBEE`），但它是 conda/PyRosetta 工程：只有 `environment.yml`、解析出的 `requirements` 为空、且仓库内**没有 `results/*.csv`** → 现阶段的"隔离 venv + pip"路线对它不适用，也没有可直接对标的产物 |
| PBEE SI | 唯一能出表出图的（4 表 / 2 图） | SI 表格带框线，默认策略能命中；但**主文的三线表不行** |

共同症状：`校验结论 = not_verifiable`。这三篇的产物里，
**标题/作者/摘要/语义章节/表格五项全崩**（标题 0/3 正确、语义章节 0/3、主文表格 0 张）。
